How Kraken works

Five layers, applied at the two trust boundaries where MarketFlow's agents hand work to each other.

01
Retrieval checkpoint
Scans reviews before the Negotiator Agent trusts them as grounding for a pricing decision.
02
Handoff checkpoint
Scans instructions before the Orchestrator forwards them on to Checkout.
03
Tiered detection
Regex pattern check, then a lightweight classifier, escalating to an LLM judge only when the signal is ambiguous.
04
Signature cache
Known-attack fingerprints get an instant decision on repeat, no re-scanning required.
05
Evidence log
Every decision -- blocked, flagged, or forwarded -- is recorded for audit and demo replay.
